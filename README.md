## Descrição

Este sistema demonstra, de forma simples e prática, os conceitos de Herança e Polimorfismo usando veículos. A classe Veiculo serve como base para Carro e Moto, que possuem características e comportamentos próprios. No Main.java, criamos e testamos diferentes veículos, mostrando na prática como o polimorfismo permite trabalhar com diferentes tipos de veículos por meio da mesma referência.
